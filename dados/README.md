# dados/

- `brutos/`: vazio de propósito. A base é sintética e não usa nenhum dado coletado de terceiros.
- `tratados/`: vazio de propósito. Os dados prontos para importação são gerados diretamente no PostGIS por `sql/dados.sql`, de forma determinística (mesmo resultado a cada execução).

Para obter as 650 feições, siga as instruções de importação do `README.md` na raiz.
